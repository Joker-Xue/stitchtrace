# Legacy 0.1.x experiment harness (historical)

These scripts produced the 0.1.0–0.1.2 evidence (four BBBC039 images, block 512, label-oracle
Cellpose/StarDist-3D fixtures, recovery and offline-replay audits). They are kept verbatim for
provenance. They expect the 0.1.x project layout (`research/`, `results/`, `data/selected/`) and
are meant to be run from the archived 0.1.2 release, not from this repository.

The experiments of version 1.0 and the accompanying paper are in [`../v1`](../v1).
